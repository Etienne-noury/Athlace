# Schémas des fiches sport

Un fichier SVG par schéma. Le titre et la légende sont dans `src/data/sport-schemas.ts`.
Pour modifier : télécharge le fichier, retouche-le (Figma, Illustrator, Inkscape…), exporte en SVG
avec le même nom, puis redépose-le ici.

Mode d'emploi complet : [docs/PHOTOS-ET-SCHEMAS.md](../../../docs/PHOTOS-ET-SCHEMAS.md)
